Chrome 扩展

共享前遮挡网页信息，用图片制作 GIF。

两款免费 Chrome 扩展，分别处理两件事：PrivacyGuard 遮挡普通网页上的信息；GIFmaker 将静态图片做成 GIF 动图。都无需账号，也不必购买原生应用。

PrivacyGuardGIFmaker

2026 年 11 月 22 日核对官方公开商店页面 · 扩展版本 0.1.0

屏幕共享

PrivacyGuard — Web Redactor

演示或共享屏幕前，遮挡普通网页中的邮箱、金额，或手动选定的姓名、表单等元素。

前往 Chrome 官方商店

扩展隐私政策（英文）

使用步骤

  1. 打开普通网页，点击 PrivacyGuard 扩展图标。
  2. 用 Mask matching text 遮挡邮箱和金额；用 Pick element 手动选择姓名或表单等元素。按 Escape 退出选取。
  3. 共享前检查整个屏幕。Undo 可撤销最后一次元素选取，Restore page 可恢复页面。界面支持简体中文和英文。

开始前先确认

这是可恢复的视觉遮挡，不是不可逆脱敏或访问控制。原始内容仍在页面内存中，动态网页也可能重新显示信息。不覆盖图片、PDF、框架、浏览器界面、其他标签页或其他应用。刷新页面会清除遮挡。

图片转 GIF

GIFmaker — Private GIF Studio

把 PNG、JPG 或 WebP 静态图片做成 GIF，调整帧顺序、停留时间、字幕和画布，预览后下载无水印文件。

前往 Chrome 官方商店

扩展隐私政策（英文）

使用步骤

  1. 点击 GIFmaker 扩展图标，添加本地静态图片，也可以先用 Try a sample 体验示例。
  2. 调整帧顺序，单独或批量设置停留时间，再选择画布尺寸和字幕。
  3. 播放预览，点击 Create GIF 后下载。需要收集网页图片时，右键该图片，按提示仅授权访问图片来源；界面支持简体中文和英文。

开始前先确认

最多添加 60 张静态图片，每张不超过 20 MB。不支持录屏、视频导入，也不会把已有 GIF 拆帧。有访问保护的网页图片可能需要先保存到本地再添加。请留意编辑器显示的尺寸和内存限制。

本地处理，也要分清网络请求。

扩展不会把网页内容或所选媒体发给开发者，也没有开发者行为统计。GIFmaker 仅在你主动导入网页图片时请求图片来源，对方服务器可以看到该次请求；安装由 Google 商店完成。本网站使用网站统计，可记录商店按钮点击，但不能读取扩展内的操作或文件。

按任务选择扩展、网页工具或原生应用。

暂时不想安装扩展？

直接使用免费网页 GIF 工具，支持符合要求的图片、视频或已有 GIF。它与扩展的输入类型和限制不同。

常见问题

这两款 Chrome 扩展免费吗？

免费，无需账号或付款即可使用。扩展可能展示可关闭的独立原生应用推荐；购买完全自愿，也不会解锁扩展功能。

PrivacyGuard 会永久删除敏感信息吗？

不会。它只改变当前网页的视觉呈现，并支持恢复。原始内容仍保留在内存中，不能用来安全脱敏文档或限制他人访问。

GIFmaker 扩展可以把视频转成 GIF 吗？

不可以。0.1.0 版本只接受 PNG、JPG 和 WebP 静态图片。网页 GIF 工具和原生应用是独立产品，输入支持不同。

如何安装？

在桌面版 Chrome 中打开对应的官方商店页面，查看权限后选择添加至 Chrome。安装由你决定；不安装也可以阅读这里的步骤和隐私政策。
