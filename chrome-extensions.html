Chrome extensions

Mask webpage details. Make a GIF from pictures.

Two free Chrome extensions for different tasks: PrivacyGuard masks details on an ordinary webpage; GIFmaker turns still images into an animated GIF. Neither requires an account or a native app purchase.

Screen sharing

PrivacyGuard — Web Redactor

Hide email addresses, currency amounts or a manually chosen page element before a presentation or screen share.

View in Chrome Web Store

Extension privacy policy

How to use it

  1. Open an ordinary webpage and click the PrivacyGuard toolbar icon.
  2. Choose Mask matching text for emails and amounts, or Pick element for a name or form field. Press Escape to leave picking mode.
  3. Inspect the whole screen before sharing. Use Undo for the last picked element or Restore page to remove the masks.

Check before you start

This is reversible visual masking, not irreversible redaction or access control. Original data remains in page memory and a changing website can reveal new content. Images, PDFs, frames, browser UI, other tabs and other applications are not covered. Reloading removes masks.

Images to GIF

GIFmaker — Private GIF Studio

Create an animated GIF from still PNG, JPG or WebP pictures. Reorder frames, adjust timing, add a caption, preview and download without a watermark.

View in Chrome Web Store

Extension privacy policy

How to use it

  1. Click the GIFmaker toolbar icon and add local still images, or start with Try a sample.
  2. Arrange frames, set individual delays or apply timing to all frames, then choose the canvas size and caption.
  3. Play the preview, choose Create GIF, and download the finished file. To collect a web image, right-click it and grant access to that image origin only when requested.

Check before you start

This extension accepts up to 60 still images, at most 20 MB each. It does not record the screen, import video or split animated GIFs into frames. Some protected web images need to be saved and added as local files. The editor displays size and memory limits.

Local processing, with separate privacy boundaries.

The extensions do not send page contents or selected media to the developer and have no developer analytics. GIFmaker contacts an image host only when you choose a web-image import; that host can see the request. Store installation uses Google. These website pages use website analytics and can count clicks on the store buttons, without reading extension activity or files.

Common questions

Are these Chrome extensions free?

Yes. The two extensions work without an account or payment. Each can show a dismissible recommendation for a separate native app; purchasing that app is optional and does not unlock extension features.

Does PrivacyGuard permanently remove sensitive data?

No. It changes the visual presentation of the active webpage and supports restoration. Original content remains in memory. Do not use it as a way to securely redact a document or restrict access.

Can the GIFmaker extension turn video into GIF?

No. Version 0.1.0 accepts still PNG, JPG and WebP images. The website GIF tool and native app are separate products with different input support.

How do I install an extension?

Open its official Chrome Web Store listing in desktop Chrome, review the permissions and choose Add to Chrome. Installing the extension is optional; these instructions and privacy policies can be read without installation.
