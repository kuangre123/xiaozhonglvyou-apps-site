Common questions

Controls, requirements, and browser playback.

Are Stardust and Guomao Never Sleeps free to play?

Yes. Both browser experiences open directly in your web browser without an account, download, or payment.

What controls work on desktop and mobile devices?

In A Brief History of Stardust, drag to rotate the 3D view and tap the timeline to jump to key cosmic eras. In Guomao Never Sleeps, use WASD keys on desktop or the on-screen touch controls on mobile and tablet browsers.

What browser requirements do these 3D web experiences need?

Both experiences use interactive 3D rendering in the browser and require JavaScript with WebGL support in a current desktop or mobile browser.

Do these browser games require installing an iPhone or Mac app?

No. They run independently in your browser and do not require installing any of the iOS, macOS, or Chrome extension tools on this site.
