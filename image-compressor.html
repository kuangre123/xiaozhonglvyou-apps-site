Common questions

Know what the tool can and cannot do.

Are my pictures uploaded?

The image tool processes selected files in your browser; it does not upload the image. The website loads its own assets and uses page and tool analytics without sending file names or image contents.

Which image formats can I use?

Start with a still JPEG, PNG, or WebP image. Available output formats depend on this browser. HEIC, RAW, SVG, and animated image conversion are outside this tool’s supported workflow.

Will the output always be smaller?

No. File size depends on the picture, dimensions, chosen format, and encoding settings. Compare the reported input and output sizes. Keep the original if a new file is larger or loses useful detail.

Does the tool edit my original?

No. Download creates a separate file. The original selected file is not overwritten, and this tool cannot scan or delete an iPhone photo library.

Can I preserve a transparent background?

Use a format that supports transparency and check the output preview. JPEG cannot keep a transparent background; conversion to JPEG uses a solid background.

Why does a file fail to open?

The browser must be able to decode it, and the tool enforces the limits shown beside its file picker. Try exporting a still JPEG or PNG from your photo app, or choose a smaller image.
