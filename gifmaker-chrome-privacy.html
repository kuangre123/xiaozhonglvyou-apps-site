Privacy, in plain language.

GIFmaker — Private GIF Studio · Version 0.1.0 · October 26, 2026

Your images stay on this device

Local files are decoded, previewed and encoded into GIFs inside the extension. There is no media upload, account, advertising SDK or analytics service. Local editing and GIF export work offline.

When you import a web image

The optional “Add image to GIFmaker” context-menu action asks permission to access the selected image's origin. After you grant access, the extension requests that image directly from its server without sending cookies or a referrer. The image server will see your request and IP address. GIFmaker does not read page contents, run scripts on websites, or monitor browsing history. Some protected, redirected or unsupported images cannot be imported.

Local storage and retention

The language choice is stored in this browser's local storage. Chrome session storage remembers the editor tab and any import error for the current browser session. Web-image imports wait in local IndexedDB until an editor consumes them. The editor discards unconsumed imports older than 24 hours when it next opens; physical deletion is not scheduled while the extension is inactive. Edited frames live in editor memory and are cleared when the editor closes. Downloaded GIF files remain wherever you save them. Uninstalling the extension clears extension storage, but does not delete downloaded files.

App recommendation

After export, the editor offers a dismissible link and a locally generated QR code for GIFmaker on the Apple App Store. Opening the link or scanning the QR code contacts Apple under Apple's policies. The native app is a separate purchase. No media or browser project is sent to the app. There is no campaign tracking or download attribution in this release.

Your controls

You can remove granted website access in Chrome's extension settings. You can use local image files without granting website access. You can close this editor or uninstall the extension to stop using it.
