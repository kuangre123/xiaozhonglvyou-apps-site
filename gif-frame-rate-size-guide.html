A practical file workflow

Choose GIF settings around the motion you need to show.

Start with the shortest useful action and the smallest readable output. More frames and larger dimensions are choices to justify, not automatic quality improvements.

Written by Bo Chen · Published and updated October 24, 2026

Open the tool

Decide what the loop must communicate

For a reaction, the expression matters. For a tutorial, the pointer movement or change on screen matters. Watch the source video and mark the start and end of that action before choosing export settings. A long introduction adds waiting without making the loop clearer.

Choose Video to GIF in the browser tool, select a local video, and set its start and end. Keep the selection within 15 seconds and the resulting sequence within 80 frames. Browser codec support matters: if the file cannot open, try a compatible video export or use the linked iPhone app workflow.

Make one change at a time

Use these as a comparison procedure rather than a universal preset. A short screen demonstration and a fast sporting movement need different treatment.

  1. Trim the source to one complete action, including the moment that explains the result.
  2. Choose output dimensions appropriate to where it will appear. Read small text at that display size.
  3. Try the tool’s 4, 8, or 12 fps sampling options, then raise the rate only if the important movement becomes hard to follow. Keep duration multiplied by sampling rate within the frame limit.
  4. Export two candidates, changing only one setting. Compare animation, readability, and actual bytes.

Check the join between the end and the beginning

A smooth middle does not guarantee a good loop. Watch the end return to the first frame and look for a distracting jump. Shorten the end, choose a different start, or deliberately hold the final state if that better explains the action.

GIF timing is stored in hundredths of a second. The viewing app can still affect the apparent pace, so inspect the saved original and one copy in the intended destination. Keep the source video; export is a new delivery file, not a replacement archive.
