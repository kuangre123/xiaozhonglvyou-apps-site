    Common questions

    Know what the tool can and cannot do.

    Does this tool upload my source images?

    No. Image decoding and GIF encoding run in this browser. The page uses website analytics, but tool events exclude image contents and file names.

    Can I convert a video or an existing GIF here?

    Yes. Choose the video or existing-GIF input type. Video decoding depends on your browser and codec. Selected clips are limited to 15 seconds, and all workflows have frame, file, and pixel limits shown in the tool. Live Photos are not imported directly.

    How do I change the animation speed?

    For photos, set one delay for the whole sequence. For video, choose the selected interval and sample rate. GIF import keeps frame timing and combines skipped-frame delays, subject to the minimum delay shown in the tool. Preview the downloaded result too.

    Will the GIF look exactly like the source photos?

    Expect changes, especially in photographs and gradients. This encoder uses a 256-color palette and flattens transparent areas onto white. Check faces, text, edges, and the background before sharing.

    Can this guarantee a file below a particular size?

    No. The final size depends on image content, output dimensions, and frame count. Read the generated file size, then remove unnecessary frames or reduce dimensions if needed.

    What if my downloaded GIF does not move?

    Open the downloaded original in a browser first. A file list thumbnail or a service’s preview may show only one frame. If the browser also shows no motion, check that you added distinct frames and exported again after editing.
