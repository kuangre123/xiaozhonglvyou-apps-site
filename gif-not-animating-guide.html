A practical file workflow

Find where the animation stopped in 4 quick checks.

Run four quick checks before rebuilding the file: open the downloaded .gif in a browser, confirm multiple distinct frames, rule out a renamed JPG/PNG or Mail Live Photo, and attach the original file rather than a preview screenshot.

Written by Bo Chen · Updated November 18, 2026

Open the tool

1. Open the downloaded .gif original in a browser

Open the GIF you downloaded directly in Safari or another browser, not only in a file-picker grid, iOS Photos grid, or message preview. If it animates in the browser, keep that file: the file itself is valid and the issue is how the receiving app or chat displays it.

If it stays still in a browser too, return to the source sequence. Confirm that you added at least two visibly different images, that the frame delay is not an unexpectedly long pause, and that you exported a fresh .gif after your last change. A single-frame GIF is a static image.

2. Follow the file through your chat or share path

Chat apps such as WeChat, Slack, Discord, and Mail handle image attachments differently. Work through one transfer step at a time so you can pinpoint what stripped the animation.

  1. Download the generated .gif file and verify that exact original plays locally.
  2. Select the original .gif from your app’s photo or file picker instead of pasting a copied preview or sending a screenshot.
  3. In Apple Mail or SMS, note that sending a Live Photo often flattens it into a still image — export an actual .gif first.
  4. Open the received message attachment in full view; many apps show a static thumbnail in the feed until tapped.
  5. Test a second destination before assuming you need to re-encode the animation.

3. Rule out renamed JPG/PNG files and screenshots

Changing a .jpg or .png filename extension to .gif never creates animation. Use an encoder that writes multi-frame GIF89a data, then save the exported file. Taking a screenshot of a moving screen also captures only one still frame.

In this site’s browser GIF tool, choose the matching input mode first — photos, video, or existing GIF — then inspect both the live preview and the downloaded .gif file. Keep your source media so you can re-export cleanly if a platform enforces a file-size cap.
