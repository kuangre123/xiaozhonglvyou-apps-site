Common questions

Direct answers for travel translator questions.

What input methods does Translation Specialist support?

It supports two-way voice conversations, continuous live interpretation, camera text translation, and typed text. It also includes travel phrase flashcards.

Does Travel Translator support camera text translation?

Yes. Camera OCR translation helps travelers read signs, menus, labels, receipts, and documents when typing the text would be slow or impractical.

Does Translation Specialist work offline?

The current App Store listing states that core language pairs have offline support. Availability can vary by language, so travelers should test the required pair before departure.

Which iOS version does Translation Specialist require?

Version 2.1.0 requires iOS 17.4 or later, according to the current App Store listing.

Should important medical or legal translations be verified?

Yes. Machine translation is useful for everyday travel, but critical medical, legal, safety, or immigration information should be confirmed with a qualified human interpreter.
